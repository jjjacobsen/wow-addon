# Performance

In **Options → Graphics**, lower **Render Scale** when the game struggles

- Start at **85%**, then try **75%** if needed
- Leave resolution on **Custom** when using a tiled window
- Keep preferred graphics quality settings and UI Scale unchanged
- Increase Render Scale when performance allows for a sharper image

This made a large improvement on the Linux laptop. If lowering it does not help, check CPU and memory load from other apps
